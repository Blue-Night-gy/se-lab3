# 界面设计约定

价格范围采用每间每晚口径, 所有住宿夜晚均满足区间, 结果另显示所选间数的全程总价. 人数按单间上限×间数筛选. 这是本轮设计约定, 需求未指定这两项查询算法.

23屏按screens.json编号, 与其他仓库的页面结构独立. 统一2间3晚260/280/310的1700元例子, 首晚300后的新价1780元, 日期改期7日至10日例子为1760元, 入住人更正不改价格和确认期限. 摄影来自独立下载的Unsplash素材, 两张双床照片另检索到公开来源后实际查看, 防止单床照片与双床标签混用.

学生: 葛茹月, 241220090. 拍摄图片与本例酒店均为设计素材及样例数据. 界面不显示实现内部的请求标识或锁细节. 本地仅提供设计导航, 业务后端在后续实验实现.
