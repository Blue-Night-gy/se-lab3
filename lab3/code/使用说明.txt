泊序酒店预订系统

环境: Node.js 24 和 npm. 运行所需的 Node.js 模块均来自标准库.
在本目录运行:
    npm run build
    npm start
使用浏览器打开 http://127.0.0.1:8788/.
程序初次运行会创建 data/bosu.db, 并生成 91 天的演示日售.
修改监听端口与数据位置:
    npm start -- --port=8790 --data=./data-alt

演示账号及权限:
- guest 和 guest2: 各自查询、下单及操作自己的预订.
- desk: 江城酒店前台, 可经办业务, 无操作日志查看权.
- audit: 江城、海湾酒店前台, 同时拥有这两家酒店的日志查看权.
- admin: 平台管理员.
上述演示账号密码均为 bosu-demo.

npm test 执行订单、价格、权限、并发与持久化测试.
npm run benchmark 使用独立临时数据库和本机 HTTP 服务, 按 10 并发运行组合查询.
常规演示数据与测试数据相互独立.
